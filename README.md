# Monthly Report v2

YouBike 臺大公館校區（站點代碼 `500119*`）2026 年 8–9 月營運指標與 ZZB 調度路線月報 v2。

## 內容

- 2026 年 8 月平日、9/1–9/9 已完成平日、9/7–9/10（9/10 為截至 07:59 的部分日）指標比較。
- 每日與逐時用量、還量、見車率、見位率及場站期間彙總。
- 2026/9/1 起 ZZB 車號調入／調出 FIFO 配對路線、車輛數與時間帶統計。
- 僅長興區域、男一舍、男六舍、男七舍相關路線顯示紅色虛線，其餘路線顯示藍色實線。
- 時段可複選，地圖以調出／調入圖標及線上箭頭呈現方向。
- 22:00–23:00 新增長興區域至明達館、明達停車場、博理館西側與鄭江樓的固定規劃路線。
- 2025/3/1–2026/9/9 臺大公館校區每日最高用量前 10 名。
- 雙北滿借／空還單站覆蓋率 v2 簡報；以城市、日期、小時、場站去重，滿借與空還分開統計。
- 雙北 ABC 逐時調度與友愛接力站數 v9 簡報；每小時分 ABC 級，比較友愛接力事件站數與其中有對應調度行為的站數。
- 友愛接力 V7 互動版、Excel 與分析簡報。

## 資料口徑

- CPS 用量為 YouBike 2.0 + 2.0E。
- 平日不含週六、週日；數量型指標採各日平均後四捨五入。
- 見車率／見位率採站點 × 小時觀測值平均。
- 滿借／空還事件與覆蓋均採單站口徑；同站同日同小時重複發生只計 1 站，跨小時或跨日期重新計算。
- 滿借覆蓋為同小時有調出／綁車的滿借站數占滿借站數；空還覆蓋為同小時有調入／解綁車的空還站數占空還站數。
- ZZB 路線依同日、同車號、同車種與時間順序，以調出對後續調入進行 FIFO 配對。
- v2 固定規劃路線未指定調度量，不列入實績輛次與車種統計。
