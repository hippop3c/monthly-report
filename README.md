# Monthly Report

YouBike 臺大公館校區（站點代碼 `500119*`）2026 年 8–9 月營運指標與 ZZB 調度路線月報。

## 內容

- 2026 年 8 月平日、9/1–9/9 已完成平日、9/7–9/10（9/10 為截至 07:59 的部分日）指標比較。
- 每日與逐時用量、還量、見車率、見位率及場站期間彙總。
- 2026/9/1 起 ZZB 車號調入／調出 FIFO 配對路線、車輛數與時間帶統計。
- 調出或調入站點任一端非 `500119` 開頭者顯示虛線；兩端皆為 `500119` 開頭者顯示實線。
- 2025/3/1–2026/9/9 臺大公館校區每日最高用量前 10 名。
- 友愛接力 V7 互動版、Excel 與分析簡報。

## 資料口徑

- CPS 用量為 YouBike 2.0 + 2.0E。
- 平日不含週六、週日；數量型指標採各日平均後四捨五入。
- 見車率／見位率採站點 × 小時觀測值平均。
- ZZB 路線依同日、同車號、同車種與時間順序，以調出對後續調入進行 FIFO 配對。
