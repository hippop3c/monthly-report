## 資料口徑

- CPS 用量為 YouBike 2.0 + 2.0E。
- 平日不含週六、週日；數量型指標採各日平均後四捨五入。
- 見車率／見位率採站點 × 小時觀測值平均。
- 65 歲以上為 65–100 歲使用者口徑；歷史月份取自 Looker／Report 的年齡分組，2026 年 9 月以 Report 平台 2.0E 有效租借與有效保險卡年齡分組補齊。敬老愛心卡為 Report 票種口徑，兩者分開計算、不互相代填。
- 臺大路線日均以該路線實際出現日數為分母；未出現的日期不列入分母，五月或九月任一月路線平均大於 1 才列示。
- 滿借／空還事件與覆蓋均採單站口徑；同站同日同小時重複發生只計 1 站，跨小時或跨日期重新計算。
- 滿借覆蓋為同小時有調出／綁車的滿借站數占滿借站數；空還覆蓋為同小時有調入／解綁車的空還站數占空還站數。
- ZZB 路線依同日、同車號、同車種與時間順序，以調出對後續調入進行 FIFO 配對。
- v2 固定規劃路線未指定調度量，不列入實績輛次與車種統計。
